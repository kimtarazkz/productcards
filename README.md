# Накладная голосом

Веб-приложение для Android: менеджер диктует товары, приложение находит их в каталоге,
считает сумму и формирует простую накладную, которую можно отправить в WhatsApp
картинкой или текстом и распечатать на компьютере.

Работает без интернета: после первого открытия все файлы и каталог хранятся на телефоне.

## Как пользоваться

1. Открыть сайт приложения в Chrome на Android → меню ⋮ → «Добавить на главный экран».
2. Каталог магазина (52 товара) загружается сам при первом запуске.
   Свой файл: ⚙ → «Загрузить из Excel / CSV».
3. Нажать 🎤 и диктовать: «полуотвод диаметр 50, 2 штуки, труба 50, 3 штуки».
   Можно диктовать несколькими заходами — всё попадает в одну накладную.
4. Проверить строки:
   - зелёная — распознано уверенно;
   - жёлтая — проверьте (под строкой написано, что смутило);
   - красная — товар не найден, нажмите на название и выберите из каталога.
   Строку можно удалить (✕), передиктовать (🎤) или поменять количество.
5. «Сформировать накладную» → «Отправить картинкой (WhatsApp)» / «Отправить текстом» / «Печать».

### Без интернета

- Кнопка 🎤 в приложении использует распознавание Chrome. Чтобы она работала без
  интернета: ⚙ → «Проверить / скачать русский язык» (нужен свежий Chrome).
- Запасной вариант, работает всегда: нажать на поле ввода внизу и диктовать через
  микрофон клавиатуры Gboard. В Gboard: Настройки → Голосовой ввод → Распознавание офлайн → Русский.

## Каталог

Таблица Excel (.xlsx) или CSV. Первая строка — заголовки:

| Порядковый номер | Название | Слова-синонимы | Цена |
|---|---|---|---|
| 34 | Полуотвод 50 | полуотвод 50, полууголок 50, пол отвод 50 | 545 |
| 47 | Труба 50 армированная стекловолокном | труба 50, труба 50 ств | 1795 |

- «Название» (или «Наименование») и «Цена» обязательны, остальные колонки по желанию.
- «Слова-синонимы» — как ещё называют товар, через запятую. Число в синониме, которого
  нет в названии («угол 45 на 20» → 45), должно прозвучать, иначе синоним не сработает.
- Первое слово названия или синонима — главное: «Кран 25 шаровый» найдётся по «кран»,
  а «шаровый кран 25» — по «шаровый».
- Размеры пишите в названии цифрами: `50`, `50/32`, `32 х 3/4`, `1 1/2`, `(1м)` — по ним
  различаются товары одного типа.
- Труба — штучный товар: «труба 50, 3 штуки, 3 метра» = 3 шт; длина учитывается, только если она есть в названии.

Встроенный каталог магазина: `sample/catalog.csv` (кнопка «Загрузить встроенный каталог магазина»).
После правки этого файла увеличьте `BUILTIN_VERSION` в `js/app.js` и `VERSION` в `sw.js` —
телефоны обновят каталог сами.

## Номер накладной

Формат `ДДММ-МСС-NN`, например `1410-100-07`:

- `1410` — 14 октября;
- `1` — номер менеджера (⚙ → «Номер менеджера»);
- `00` — скидка в процентах (пока всегда 00);
- `07` — порядковый номер за день, каждый день с 01.

## Для разработчика

- Без сборки: обычные HTML/CSS/JS, можно положить на любой статический хостинг (GitHub Pages).
- `js/parser.js` — разбор фразы в позиции, `js/catalog.js` — импорт каталога,
  `js/invoice.js` — номер и вид накладной, `js/app.js` — интерфейс, `sw.js` — офлайн-кэш.
- После изменения файлов увеличьте `VERSION` в `sw.js`, иначе телефоны продолжат брать старые из кэша.
- Тесты разбора: `node --test tests/parser.test.js`.
- Чтение Excel: SheetJS 0.18.5 (`vendor/xlsx.mini.min.js`, лицензия Apache-2.0).
